扩展指南 · 如何新增一种效果器（如 合唱 / 混响 / 颤音）

系统按「注册表 + 参数描述符 + 基类旁路」组织：新增一种效果不改动任何 UI / 引擎 / 模型代码，只需三步 ——

// 1. 新建 js/effects/chorus-effect.js，继承基类并描述「叫什么、有哪些参数」
FX.ChorusEffect = class ChorusEffect extends FX.BaseEffect {
  static id = 'chorus';              // ① 注册表唯一键（也用于持久化）
  static name = '合唱 Chorus';
  static description = '…';
  static params = [                  // ② 参数数组 —— 面板/滑杆/存取全部自动生成
    { key: 'rate',  label: '速率', type: 'range', min: 0.1, max: 8,
      step: 0.05, def: 1.2, unit: 'Hz' },
    { key: 'depth', label: '深度', type: 'range', min: 0, max: 100,
      step: 1, def: 40, unit: '%', log: true }
  ];

  _build(ctx) {                       // ③ 接线：this.fxIn / this.fxOut 为内部链两端
    // …创建 LFO、DelayNode 并连接…
    this.fxIn  = inGain;
    this.fxOut = sumGain;
  }

  onParam(key, v) {                   // ④ 把参数实时映射到节点（用 FX.utils.automate 平滑）
    // if (key === 'rate') FX.utils.automate(this.lfo.frequency, v, 0.02); …
  }
};
// 2. 注册（js/main.js 内加一行）
FX.Registry.register(FX.ChorusEffect);  // 立即出现在「效果器库」并可加入信号链

关键扩展点： js/effects/base-effect.js（基类与参数协议）、 js/effects/registry.js（注册表 + 链模型）、 js/audio/engine.js（音频图）。同类型效果（如合唱）可多个并联进链，顺序即音色顺序。
